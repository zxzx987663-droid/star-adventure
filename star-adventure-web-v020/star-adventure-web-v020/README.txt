星星大冒險 Web Build 0.2

這是一個可部署到網路主機的多人 Web Game 專案，不是給朋友下載安裝的程式。
部署後，所有玩家只需要同一個 HTTPS 網址。

目前 Build 0.2：
- 建立/加入 4 碼房間
- 1~6 人 Lobby
- 角色不可重複
- 小桃身份由伺服器保存
- DEV Bot 補滿六人
- PC/手機操作
- Socket.IO 即時位置同步
- 斷線 30 秒內可用同一瀏覽器身份重連
- Host 轉移基礎
- 製作人頁面
- /health 健康檢查
- Render Blueprint + Dockerfile，方便部署

下一版：共用關卡系統 + Level 1。

## 本輪抓到並修正的問題

- 壓板必須分別站在不同位置，不能用同一區內人數充數。
- 貨物與角色的水平碰撞接入共用物理，避免客戶端穿貨物後再被伺服器拉回。
- 翹翹板入口／出口高度平滑銜接，避免圓形貨物卡在台階邊緣。
- 假人接近終點會壓縮集合，避免跟隨隊列太長而阻塞全員判斷。
- 修正早按「下一關」時不切換的情況。
- 第五關增加分段檢查點；小怪採可見的巡邏／打瞌睡節奏，保留推物件及避怪機關。
- 補內建繁中文字型與表情字型，避免無中文字型裝置出現方框。
- 結局小桃私密憑證不廣播給其他玩家；公開角色 ID 和回房憑證分離。

## 尚未驗證

- **沒有真人遠端測試者參與**；兩個 Browser Context 是自動化裝置模擬。
- 真實 iPhone／Android 的鎖屏、長時間背景、電池節流、Wi-Fi 與行動網路切換。
- 不同電信／地理區域的延遲、Render 實際 instance 負載、六位真人的完整聚會流程。
- 原規格的每關預估時長與最終美術／音樂體驗。
- 本次僅交付可部署 ZIP，沒有將此版發布到既有 Render 網址；部署後的實站仍需另外驗證。

建議部署後以一位遠端朋友＋假人先跑一次，尤其測試小桃第五關重新整理及背景回來。這是實機驗證的剩餘範圍，不代表關卡仍有未實作的 Coming Soon。

## 重現

```bash
npm ci
npm test
npm install --no-save playwright
npx playwright install chromium
npm run test:browser
npm run test:multiplayer
```

若使用已安裝的 Chromium，可設定 `CHROMIUM_PATH`；可用 `PLAYWRIGHT_MODULE` 指向 Playwright 套件。這些只用於 QA，Render 運行不需要 Playwright 或瀏覽器。

機器可讀結果與測試輸出附於 `docs/qa/`。

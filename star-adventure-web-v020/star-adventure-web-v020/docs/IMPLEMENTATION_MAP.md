## 0.3.2 基準修正

- 原本的大範圍人數計算改為三塊互不重疊的碰撞區域。
- 修正原本移動木板只有視覺、沒有支撐碰撞的情況。
- 原版 token 廣播會暴露回房身分；改為公開角色 ID 與私密 resumeKey 分離。
- 原版玩家每次收到整房訊息會改寫本地座標；改成初始快照、輕量 frame、獨立 stage 訊息。
- 將單頁原型拆成共用物理、伺服器關卡邏輯、前端顯示，保留原技術堆疊和 /health。

## DEV 協助的界線

- 正常六人關卡沒有被刪減；假人模式是明確的測試輔助。
- 自動協助時，假人可定位、補配對答案、搬彈、誘敵、替開箱按住；三個假人在翹翹板區會提供穩定平衡，方便一人測試貨物運送。關閉自動協助後回到實際玩家位置力矩。
- `完成配對謎題`、`全員到集合點` 等按鈕是獨立的 DEV 操作，不會在真人遊玩中自動觸發。
- 1–5 人測試請補假人；機關仍保留六人分工，沒有另做簡化關卡。

## 測試方式與限制

- 機制測試使用固定時間步進，會直接安排玩家位置或機關狀態來覆蓋分支；L2 實體輸入是把指定玩家放到地板後執行物理 tick，並非以滑鼠假冒任意符號指令。
- 路徑測試用實際共用物理更新驗證 BOSS 兩種通過方式及 L5 各個平台／斷崖，不是只檢查函式回傳值。
- 六個 Socket.IO client 是實際連線；瀏覽器測試也使用六個獨立身分，但為快速覆蓋會使用房主 DEV 跳關／設置情境。**這不是六位真人不開 DEV 從頭到尾通關的紀錄。**
- 主流程瀏覽器驗證選角 → 各關畫面與部分操作 → 重連 → L5 全員按住 → 五秒純白 → 分流台詞 → 五人送星 → Birthday Ending → Party Room → RESET GAME。
- 仍需真人確認難度、語音協作時間、手機實機手感、長時間穩定度與跨網路延遲。完整項目見 `MANUAL_TEST_CHECKLIST.md`。

# CHANGELOG — Build 0.4.1

基礎版本：0.4.0-alpha.1。依 `STAR_ADVENTURE_BUILD_0.4.1_IMPLEMENTATION_SPEC_FINAL.md` 更新，未從零重寫。

## 保留

- 原 Express / Socket.IO 伺服器、六人房間、唯一選角、私有 resume key、momoToken 與同裝置重連。
- Level 1 的三壓板、遠端拉桿、移動板、第四人斷橋與碎片集合。
- 五人獨立送星、生日祝福、Party Room、製作人頁與通關後解鎖內容。
- 原有輸入預測、遠端插值、觸控、音效設定與 DEV 基礎功能。

## 依 FINAL Spec 取代的關卡機制

- L2：五座實體洞穴、每洞四位不同執行者、每棒手動開始、私有定時顯示、踩第一格才開始輸入倒數、單洞失敗重新分工。第四／五洞雙讀題者、逐棒真假身分、唯一有效答案檢查；雙人同時開始只接受一次。
- L3：長山路、三人推貨／三人開路、橋／門／風扇、超員加速、貨物乘坐與壓人；最後大坡要求六人，另設坡腳重試點與蘑菇笑點。
- L4：越過中央 BOSS，移除舊砲台／彈藥／命中流程；可跳過或等躍起走下方。壓扁慢行、0.5 秒救援、0.1 秒保護。每人橋尾按鈕保留完成紀錄，6/6 開橋，已完成人員掉落回橋尾。
- L5：四段個人檢查點障礙賽、移動／窄／落下平台、小怪與個人死亡。普通终點全員按住三秒，直接進入五秒純白，之後小桃／其他玩家各自收到不同台詞，再接既有生日 Ending。

## 系統與維護

- 新增房主 Reset current level 與需二次確認的 RESET GAME；後端驗證房主、確認 nonce、有效期與關卡 epoch。
- 重連同步洞穴分工／答案／時間戳、貨物／機關、BOSS 個人完成、壓扁／救援／保護時間、L5 檢查點／抵達／按住、結尾階段。
- 新關卡機制集中在 `levels.js`；共用地形與 hitbox 在 `public/geometry.js`；視覺由 `level-view.js` 與 `asset-registry.js` 處理。
- Manifest 支援角色、BOSS、敵人、貨物、平台、背景及 UI 圖示；visual size、anchor、動畫 sheet 與碰撞資料分開。
- 跳躍由 -465 改成 -600，最高約 170 像素；調整並實測 BOSS 兩種通過方式與 L5 各段跳躍路徑。
- 移除大量分片字體；改用約 96 KB 合計的兩個字體子集與系統字體備援。
- 保留 20 Hz 移動封包、5 Hz 關卡狀態。私有線索只在內容改變時傳送，手動開始時立即發布一次狀態；逐格動畫不走網路。
- 增加各關 DEV 操作與生存狀態檢視。舊存檔的 L2–5 可保留房間身分並移至該關新版起點。

## 修正與驗證

- 防止第四關全員壓扁卡死：壓扁者可慢走靠近隊友並協助救援。
- 修正新生存規則與旧版自動復活互相干擾的風險。
- 加上答案實體移動時間估算，避免產生在指定時限內過度緊迫的符號組合。
- 白畫面覆蓋完整介面並停止音效；Reset 返大廳時清除白畫面。
- 修正手機橫向遊戲視窗與控制列配置；驗證多指移動／跳躍與 pointer release。
- 更新全部交付文件及新規格測試；舊版已被取代玩法的測試不列入 0.4.1 通過數。

# Manual Verification Required

以下項目**尚未由真人或實體手機驗證**。Chromium 手機視窗、觸控事件與六個瀏覽器 context 只是模擬，不能視為真機／六人實玩通過。

| 項目 | 實際做法 | 通過條件 |
|---|---|---|
| 六名真人完整一輪 | 六個角色含小桃，各自裝置、外部語音；關閉 DEV 自動協助，從建立房間自然走完 L1–5、白幕、生日、Party | 无需 DEV 解卡；各人理解任務、共同完成 |
| L2 真實語音難度 | 每洞四棒；雙 Reader 各念自己的答案；測連續四個相同符號 | 讀取時間合理、能分辨真假；長按不連輸入，重按能輸入 |
| L3 三推三開路 | 三人推、三人走高台；放手回滾、下坡刻意多推，再收手；最後六人同步 | 坡度與速度直覺、不抖動；語音可協調；掉落／存點清楚 |
| L4 主觀公平性 | 不用 DEV，分別直接跳過與等跳起穿越；救援後重試 | 預兆看得懂、有挑戰但不依賴猜測或極限延遲操作 |
| L5 難度位置 | 真人比較 L1、L4、L5，觀察三種怪各 2–3 秒後再過 | 能理解規律，整体難於 L1、低於 L4 |

| 背景與鎖屏 | 手機切 App、鎖屏 10–60 秒再回來 | 自動重連、輸入不黏住、動畫／倒數回正 |
| 六人不同網路 | 家用 Wi-Fi + 行動網路，含 100–250ms 延遲／短暫丟包 | 互動與 Boss 提示可用，角色不長時間跳位 |

| 音效／生日演出 | 實機先允許音效；六人終點按住 3 秒，檢查白幕與五人獨立送星 | 白幕約 5 秒無字無 UI 無聲，小桃與他人台詞正確，五人送完才合併 |

## 已自動驗證、但仍需上述實玩補足的部分

- 六個 Socket.IO client 的身分、重連、私有答案、安全鎖定、Reset。
- 六個 Chromium context 的 Reader 隱私、E／手機互動、momo reload、生日及 Party。
- 手機模擬雙指跑跳、控制鍵放開；390×844／844×390／1280×850 HUD 與面板界線。
- 真實角色物理下的 L3 平台跳躍、Boss 兩路通過、L5 所有缺口四種平台相位。

## 已知限制

Placeholder 美術與簡易合成音效；語音需外部工具。DEV 假人會協助／傳送，不能用假人代替難度實測。只有單一 server instance；跨部署保留依賴持久磁碟。舊版 L3 首次升級需要重新從該關起點玩；同版 reconnect 不重置。

本次沒有使用者的已部署 Render 網址，因此未將「Render 線上驗收」標記為已完成。未發現的實機／真人手感問題仍可能存在。
